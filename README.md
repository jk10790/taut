## Zero Waste Compute

`taut` is a drop-in library and proxy that sits between your application and your
LLM provider. It caches repeated requests, compresses bulk payloads, and routes
each request to the cheapest model that can handle it — so tokens you do not
need to send never leave your network.

### What it does

- **Semantic caching** — identical and near-identical requests are served
  locally. Embeddings run on ONNX; no PyTorch. In-memory FAISS for development,
  Redis vector search for production, with per-tenant namespace isolation.
- **Payload compression** — JSON arrays become columnar text; Python source is
  stripped of docstrings and annotations via AST rewriting. Measured on the
  checked-in corpus: **54% reduction** on JSON logs, **58%** on Python source.
- **Tiered routing** — request complexity is scored from payload size, tool
  count and keywords, then routed to `gpt-4o-mini`, `gpt-4o` or `o3`.
- **Prefix alignment** — static content is pinned to the top of the prompt to
  maximise provider-side KV cache hits; Anthropic requests get explicit
  `cache_control` breakpoints.
- **Output restraint** — YAGNI, terse or structured constraints, optionally
  varied by routing tier, to cut output tokens.

Every number above comes from [`tests/benchmarks/baseline.json`](tests/benchmarks/baseline.json),
regenerated by `pytest tests/benchmarks -m bench`. Every capability listed is
bound to a test in [`docs/claims.yaml`](docs/claims.yaml); CI fails if a claim
here has no passing test behind it.

### What it does not do

Prose compression is eleven filler-phrase substitutions. On the corpus it
measures **~0%** on retrieved documents and chat transcripts — it is not a
document compressor, and `taut` will not meaningfully shrink your RAG chunks.
Compression pays off on structured payloads: logs, JSON, code.

There is no health-based or load-aware routing. `taut` fails over on error and
opens a circuit breaker on a repeatedly failing model, but it does not probe
provider CPU or latency. See [Limitations](docs/limitations.md).

## Quick Start

`taut` is not yet published to PyPI. Install from source:

```bash
# Install with the extras you need. The proxy needs FastAPI and uvicorn,
# which live in the `proxy` extra.
pip install -e ".[cache,proxy]"

# Start the proxy server
python -m taut.proxy.server --port 8000
```

Point any OpenAI-compatible client at it:

```python
from openai import OpenAI

client = OpenAI(
    api_key="your-api-key",
    base_url="http://localhost:8000/v1",  # Point to taut
)
```

Or use it directly from Python — see [Integration](docs/integration.md) for the
full example.

## Observability

`taut` reports per-layer metrics at `/v1/taut/metrics`: cache hit rate, tokens
saved (counted with the model's real tokenizer) and estimated cost saved
(computed from provider pricing). Models with no pricing data report zero saved
rather than a guess.

## Development

```bash
pip install -e ".[cache,proxy,redis,dev]"

pytest -m "not e2e and not costly"   # unit + integration
pytest -m e2e                        # live proxy over localhost
pytest tests/claims                  # documented claims
pytest tests/benchmarks -m bench     # measured compression
ruff check .
```

`pytest tests/benchmarks -m costly` runs fidelity checks against a real
provider — it verifies compression does not change the model's answers. It
spends money and is excluded from CI.
